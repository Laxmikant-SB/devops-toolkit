# DevOps Toolkit

Production server management toolkit for Linux servers.

## Structure
- scripts/monitoring/ — system health and alerting scripts
- scripts/backup/     — backup and restore scripts
- scripts/deployment/ — deployment automation scripts
- scripts/security/   — security audit scripts
- config/             — configuration files
- docs/               — documentation

## Usage
Each script is self-contained and configurable via config/settings.cfg
